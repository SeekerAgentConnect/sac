# Roboto Mono capture font

`RobotoMono-Latin-400-700.woff2` is the Latin WOFF2 served by Google Fonts for Roboto Mono 400, 500, and 700 (`v31`). It is committed so offline captures do not depend on a machine's monospace fallback.
