## What the checks hold

- `:designsystem` has no Gradle project dependency and no app-model, ViewModel, wallet, storage,
  Firebase, gRPC, or HTTP-client import. `:app` is the one-way consumer.
- The finalized export's light/dark palette, all six source-chip colour pairs, the 2–32 spacing
  scale, 4–28 radius scale, and 12–36 type scale are centralized under the theme package.
- Roboto and Roboto Mono are bundled under `res/font`; their upstream hashes and OFL texts are
  pinned. Every text style has explicit CSS-derived line height/letter spacing, disabled font
  padding, and fixed centred untrimmed line boxes.
- Material surface tint, tonal elevation, default shapes, ripple colour, and implicit minimum
  component size are replaced by explicit design-system values.
- Production Kotlin outside the theme package contains no raw `Color(0x…)`, `.dp`, or `.sp`
  literal. The check is wired into both root Gradle `check` and `pnpm check:android`.
