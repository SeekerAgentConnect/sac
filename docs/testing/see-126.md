# SEE-126 — CopyTrading demo trader UI

Password-gated HTML on the existing gateway origin (`/trader`) for hackathon judges. The UI is a
client of the CopyTrading `/v1` API. The API token never enters the browser. `/v1` is not on the
public origin.

## Automated

From the repository root, after `cd publisher && go test ./...` (also `pnpm check:publisher`):

| Check | Result |
| --- | --- |
| Publisher tests with `PUBLISHER_CREATE_LIMIT` unset (default unlimited) | PASS |
| Optional create cap refuses further new signals with 429 | PASS |
| Named bcrypt file; unknown and wrong passwords share a message | PASS |
| Deleting a password line revokes an open session on the next request | PASS |
| Session cookie is HttpOnly, Secure, SameSite=Strict, Path=/trader | PASS |
| Create / list / cancel call `/v1/requests`; no amount field; token absent from HTML | PASS |
| Excess login failures and excess creates are refused | PASS |
| Cross-origin POST does not reach the API | PASS |
| Chrome same-origin form POST with `Origin: null` and `Sec-Fetch-Site: same-origin` logs in | PASS |
| `Origin: null` without `Sec-Fetch-Site: same-origin` is still 403 | PASS |

Public URL used in the unit tests: `https://feeds.example.com/trader` (httptest).
