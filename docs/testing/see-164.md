## Scope

SEE-164 changes the presentation and browser interaction of the existing password-protected
feed-gateway administration. It adds no administration API, store, credential kind or source of
truth. The existing handlers and `storage.PublisherAdminStore` remain authoritative for login,
registration, capability changes, access policy, credential rotation and revocation, and forgetting
a server.

The Linear prototype is the visual and interaction source of truth: dark theme, lime accent,
bundled Roboto and Roboto Mono, responsive sidebar, **Servers**, **Add server**, gateway address and
**Log out**; login; the registered-server table; Add-server drawer; server detail; and the one-time
credential page. The production page also retains SEE-162's newer restricted-feed controls, styled
inside the same drawer and detail page. Repository explanatory copy is retained word for word where
the prototype keeps it.
