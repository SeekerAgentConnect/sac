# SEE-178 — multi-wallet UI redesign

## Acceptance coverage

- The Wallet tab renders saved profiles as collapsible cards and permits only one expanded card.
- **Add wallet** opens the shared network and wallet-app bottom sheet.
- Connection wallet selection uses declared-network and undeclared-network modal sheets.
- Declared-network mismatches remain visible, explain the mismatch, and are disabled.
- **Use this wallet** starts disabled and enables only after a selectable profile is chosen.
- The connection picker contains no wallet-app radio list; adding from it opens the shared sheet,
  with a single declared network preset when available.

## Automated checks

- `WalletScreenTest` covers card expansion, copy accessibility, actions, and add-sheet choices.
- `ConnectionWalletPickerTest` covers eligibility, selection gating, add presets, undeclared
  networks, and the absence of wallet-app choices.
- `AppNavigationTest` covers the sheet graph and process-state round trips.
- `WalletActivityTest` covers adding and binding through the real activity with fake external
  adapters.

## Visual checks

Four 390×844dp Roborazzi captures are committed under `app/src/test/snapshots/images/screens/`:
`wallet.png`, `wallet-add.png`, `wallet-picker-declared.png`, and
`wallet-picker-undeclared.png`. They were compared after scaling from Roborazzi's 3× output to the
handoff's 2× PNGs. Sheet origins differ by at most 0.5dp from the references (235dp, 395dp, and
316dp respectively); the Wallet card, collapsed card, and Add wallet button align to the handoff.

The handoff zip and extracted folder remain local and untracked.
