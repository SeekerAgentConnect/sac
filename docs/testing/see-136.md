## Final graph and responsibilities

There are exactly two active connection modes:

| Mode | Phone talks to | Shared service | Owner result goes to |
| --- | --- | --- | --- |
| Direct private | An independently operated direct server | None | The same direct server |
| Public feed | `feed-gateway` snapshot/stream endpoints | Feed gateway, with optional Centrifugo/Redis fan-out | Nowhere; decisions and results stay on that phone |

The final root responsibilities are:

| Root | Responsibility | Runtime relationship |
| --- | --- | --- |
| `server-sdk/` | Embeddable TypeScript Direct Server SDK | Library only; no MCP, feed, demo or deployment dependency |
| `mcp-server/` | Self-hosted direct MCP application and executable package | Consumes only SDK public exports; source, npm and Docker entry points share one CLI |
| `feed-gateway/` | Shared public-feed storage, publication, reads and delivery | Independent Go service; no private request/result routing |
| `publisher-support/` | Common Go publication/outbox source library | Non-deployable and unpublished; used only to build the demos |
| `demo-copytrading/` | Optional CopyTrading feed source | Independent application, identity, credential and SQLite file |
| `demo-prediction/` | Optional Prediction feed source | Independent application, identity, credential and SQLite file |
| `android/` | Direct connections, feed subscriptions, local review/approval/history | The only owner-decision and wallet boundary |
| `deploy/` | Independent application, ingress and operator presets | Optional orchestration; it does not add a third connection mode |

PR #36 was reviewed before reconciliation. It changed only `docs/architecture.md`; its two-mode
and component-boundary narrative remains intact. This change makes focused status/path corrections
and does not restore gateway-private routing.
