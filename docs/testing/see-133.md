## Compatibility and rollback

The rename preserves the schema-v3 SQLite bytes, `/data/broadcast.db`, `broadcast-data` volume,
`seeker-broadcast` standalone Compose project, `BROADCAST_*` settings, public protocol packages,
server/publisher IDs, ports 8090/8091, and uid/gid 10001. The old `check:broadcast` script name is a
one-window alias to `check:feed-gateway`; active callers use the new name.

Before update, stop the writer and archive the existing local volume. Rollback across a schema
change restores the complete pre-update file/volume and starts the matching old image; an older
binary must not open a newer schema. No credential, endpoint, or identity is regenerated because a
folder or service name changed.
