## Part 2 step 7 — physical Seeker

A physical Seeker (`SM02G4061936191`) was attached and visible to the Android SDK on 2026-09-18.
The public gateway at `https://hermes.tail5e20a8.ts.net:8443` was reachable and returned its
structured `no_such_server` response for an unknown server ID. The two exact deployed CopyTrading
and Prediction feed references/server IDs were not present in this checkout or in the SEE-106
evidence, and this environment had no SSH or publisher control-plane access from which to obtain
them. The built debug APK also could not replace the phone's existing app because Android reported
`INSTALL_FAILED_UPDATE_INCOMPATIBLE` for a different signing key; the existing installation and its
data were deliberately not uninstalled. Those references and a safely installable build are inputs
to every line below. The app now has the onboarding UI; the blockers are deployed-demo
identity/access and device signing, not missing phone UI.

a failure. In that configuration only the background-notification lines are unavailable; onboarding,
the authoritative snapshot and foreground stream remain valid checks once the two references are
