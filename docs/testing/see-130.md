## Acceptance result

publisher listeners only. Private invitation, binding, request and result procedures are absent
from both; old hosted invitation paths return 404. Direct request/result behavior and public feed
publication to two independent subscribers pass the joined integration run.

Old Android gateway-private records migrate to an explicit inert state with no active mode,
credential or cached manifest. Startup cleanup marks waiting result delivery undeliverable, removes
unfinished proposals and sync/notification ownership, and is safe to run again. Activity history
and active Direct/Feed records are not removed. Old invitation links can only show the retirement
explanation; old request notifications can only open the retired connection details. Neither path
contacts a gateway, sidecar or wallet.

## Migration, backup and rollback

Before starting this build, stop the gateway and copy `broadcast.db` together with any `-wal` and
`-shm` siblings. Opening it upgrades schema 2 to 3 in one transaction. Rollback requires stopping
the new binary, restoring that complete pre-v3 backup, then starting the old binary. Starting an old
binary on schema 3 is refused, and schema 3 cannot recreate deleted invitation tokens, device
credentials or private requests.

Android retirement is intentionally one way for secrets and unfinished work. Reinstalling an older
APK cannot restore a deleted device credential; use a fresh direct pairing code. The inert record
preserves enough non-secret identity and timing context for the owner, while Activity history remains
independent.
