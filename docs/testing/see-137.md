## Status decision

SEE-137 has reproducible local evidence for its ownership, health, generic TLS/HTTP2 configuration,
combined-host topology, package and documentation changes. The remaining items require infrastructure or
clients absent from this host and stay explicitly **NOT RUN**.

Parent SEE-128 remains open. Its required live container, public-ingress, broker, client and physical-device
acceptance has not been completed, and the blockers above are not waived by this follow-up.
