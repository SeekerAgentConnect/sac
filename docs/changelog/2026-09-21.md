# 2026-09-21

## Fixed

- **SEE-142: MCP h2c healthcheck leaked HTTP/2 sessions on timeout.** The
  container probe rejected after the deadline but left the request and
  `http2.connect` session open, so `node mcp-server/dist/healthcheck.js` could
  stay alive until Docker's outer timeout. Timeout and error paths now destroy
  the stream and session, keep the original error, and let the process exit
  nonzero without `process.exit()`. HTTP/1 and native-TLS checks are unchanged.
