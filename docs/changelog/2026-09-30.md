# 2026-09-30

## Changed

- **Redesigned the Android multi-wallet UI (SEE-178).** The Wallet tab now uses one-at-a-time
  collapsible cards and a dedicated add-wallet bottom sheet. Connection wallet selection is a
  modal sheet that keeps incompatible networks visible but disabled, requires an explicit
  selection before **Use this wallet**, presets the server network when adding from a declared
  picker, and keeps wallet-app selection exclusively in the add-wallet flow.
