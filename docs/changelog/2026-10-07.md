# 2026-10-07

## Released

- **First public releases: every component at `0.0.1` (SEE-182).** The eight `<component>-v0.0.1`
  tags were pushed on the SEE-182 merge commit `f3521ff` and the release workflow published each
  one, with no partial release to retry:
  - npm, `latest`, with SLSA provenance: `@seekeragentconnect/server-sdk@0.0.1`,
    `@seekeragentconnect/mcp-server@0.0.1` and `@seekeragentconnect/mcp-skr-staking@0.0.1` (both
    servers bundle SDK 0.0.1).
  - GHCR, public and anonymously pullable for `linux/amd64` and `linux/arm64`, tagged `0.0.1`,
    `sha-f3521ff…` and `latest`: `mcp-server`, `mcp-skr-staking`, `gateway`, `gateway-centrifugo`,
    `demo-signals`, `demo-prediction`.
  - Android: `sac-0.0.1.apk` (`versionCode` 2, `io.github.brrenat.seekervault`) with `SHA256SUMS`
    on the [`android-v0.0.1`](https://github.com/SeekerAgentConnect/sac/releases/tag/android-v0.0.1)
    release — the repository's latest release — signed with the permanent release key, certificate
    SHA-256 `3b29a71f…2164f28`, built with push, Solana RPC and the relay/Discover URL configured.
  - The npm integrities, image digests and APK hashes are recorded in
    [`docs/guides/installation.md` § Published versions](../guides/installation.md#published-versions);
    `do-deploy` and its Docker Hub references are unchanged.

## Changed

- **Documentation reflects the shipped releases.** `docs/guides/installation.md` no longer tells
  readers to check whether anything is published: it lists the `0.0.1` identities to pin and the
  signing certificate to compare `apksigner` against. `docs/development/releases.md` records that
  the first releases went through the one-time owner setup (the release key exists; the GHCR
  packages are public) and that the "treat as unpublished" rule now applies only to new packages,
  images or components. The README no longer says CI runs by manual dispatch. The public docs site
  (`SeekerAgentConnect/docs`) moved its install tabs to the published `@seekeragentconnect` packages
  and the public GHCR images, replaced the retired `deploy/` paths, added how to get and verify the
  app, and closed the "packages do not resolve" and "repository is private" discrepancies on its
  Source mapping page at `f3521ff`.
