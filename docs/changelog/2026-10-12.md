# 2026-10-12

## Changed

- **Nx Release plans and publishes independent components (SEE-187).** Nx 23 orchestrates build,
  lint, typecheck, test and check targets, with affected execution in CI and no Nx Cloud. Versions
  come from Conventional Commits and the existing `<component>-v<version>` tags. A push to `master`
  opens one release pull request; merging it tags that commit and dispatches the existing npm,
  GHCR and Android publish jobs. `gateway` and `gateway-centrifugo` stay split by file. An SDK
  change includes the MCP servers that vendor it. Android `versionCode` advances once per planned
  release. Before 1.0, a breaking change bumps minor and a feature bumps patch. `pnpm release:bump`
  is gone. Nothing in this change publishes.

- **Every component bumped to `0.0.2`.** `pnpm release:bump <component> 0.0.2` for all eight
  components in `release/components.json`: `server-sdk`, `mcp-server`, `mcp-skr-staking`,
  `gateway`, `gateway-centrifugo`, `demo-signals`, `demo-prediction` and `android`. The npm
  manifests and the MCP servers' version constants move with it, and the Android `versionCode` goes
  from 2 to 3 (`previousVersionCode` 2). The release carries what landed since `0.0.1`
  ([2026-10-10](2026-10-10.md), [2026-10-11](2026-10-11.md)). Nothing is published until the
  `<component>-v0.0.2` tags are pushed on the merge commit
  ([docs/development/releases.md](../development/releases.md#releasing)).
