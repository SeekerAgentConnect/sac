# 2026-09-24

## Features

- **Per-server colour marker (SEE-83).** Each connection stores one of six colours locally.
  Pairing assigns the next free colour, the connection sheet can change it, and the paired-server
  avatar and waiting-for-you pill use that fill and ink. Removing a connection frees the colour.
  See `docs/wiki/server-colour.md`.

## Development

- **Linear MCP server in the project config.** `.mcp.json` (Claude Code) and `.codex/config.toml`
  (Codex) declare `linear` at `https://mcp.linear.app/mcp`, sending a Linear API key from
  `$SEE_LINEAR_TOKEN` as a bearer token, so agents can read `SEE-…` tickets without an interactive
  OAuth flow. See `docs/development/tickets.md`.
