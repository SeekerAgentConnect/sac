Who reads it
Every app whose build names this gateway, anonymously, through FeedService.GetClientConfig. It is the same answer for everyone, and asking records nothing. No publisher, manifest, signal or link can set or override it.

Everything on this page is public. Any client can read every value here, including a URL's path and query. Never put a secret here: a URL with a user name or password is refused, and if your RPC provider needs a secret key, put a proxy of your own in front of it and enter the proxy's URL instead.

Solana RPC endpoints

One endpoint per network. Leave a field empty for no endpoint: the app then reads nothing on that network and says so, and never reads it through another network's endpoint. The app proves each one serves the network it is listed for before trusting anything it reads.

An absolute https:// URL with no user name, password or fragment, at most 512 bytes. Plain http:// is accepted only for localhost, 127.0.0.1 or [::1].

SAC swap service fee

The fee the app adds to a feed swap's output, credited by the swap program to token accounts you created beforehand. It applies to swaps on the chosen network only, and only when the output mint is listed below. 0 is no fee, and is the default.

One mint=token_account per line: the classic SPL token account, owned by the wallet above, that receives the fee in that mint. Each mint once; an account is never the owner wallet itself or its own mint.

A nonzero rate needs a network, an owner and at least one account. Anything you fill in is checked even at 0, and a configuration that breaks a rule is refused whole — nothing is saved, and no rate or recipient is adjusted to make it fit.
