The one call

Ordinary authenticated HTTP, made by the developer's own server when one of its requests changes. It carries a handle the owner's phone gave that server directly, and a hint of one of two words; the gateway builds the message itself. The walkthrough is in docs/guides/server-development.md.

POST {{$n.RelayCall}}
Content-Type: application/json
Authorization: Bearer <the credential above>

{"version":"1","handle":"<from the paired phone>","hint":"created"}

This developer needs no Firebase project and no service-account credential. The gateway's own credential stays with this deployment and is never handed out; a relay credential grants one thing — asking that a phone which already authorized this server be told to go and read that server for itself.
